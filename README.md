# SIA Solution

Web design & development studio (Karachi) — landing pages, business websites, online
stores, AI chatbots and AI agents. We build it first, you pay after.

## Repo structure

```
frontend/   React + Vite + Tailwind business website (siasolution.com)
```

## Getting started

```bash
cd frontend
npm install
npm run dev
```

Build for production:

```bash
cd frontend
npm run build
```

## Tech stack

- React 19 + Vite
- Tailwind CSS
- lucide-react (icons)
- EmailJS (contact form)
